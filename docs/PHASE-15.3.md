# Focus 0.12.2 + Focus Blocker 0.9.4: your icon

- The app uses your icon everywhere: installer, Start menu, taskbar, tray and the title bar. It sits on a white rounded tile so the black lines stay visible on a dark taskbar.
- The Firefox extension uses the same icon (toolbar and about:addons). Extension version 0.9.4; nothing else changed in it.
- Dragging on the To-do board keeps tracking the mouse even if it leaves the card, and the webview can no longer start its own drag first.
- Includes everything from 0.12.1 (drag between days, click a card to add a description).

Install: unzip Focus-0.12.2-installer.zip and run the setup (upgrades in place). For the extension, load focus-blocker-0.9.4.zip the same way as before. Windows may keep showing the old icon for a few minutes until its icon cache refreshes.
