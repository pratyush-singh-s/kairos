# Files in notes: Focus 0.21.12.B for Windows + Focus 0.24.0 for Android

Attach any file to a note (zip, PDF, PowerPoint, Word, photos, anything up to 2 GB). It goes to your
other devices with the normal Wi-Fi sync, so a file you attach on the laptop can be opened on the
phone, and the other way round.

**Install both**: `Focus-0.21.12.B-installer.zip` on the laptop and `Focus-android-0.24.0.zip` on the
phone. Both versions are needed to sync: an older one on either side says to update. Your notes,
to-dos and deadlines stay.

## On the laptop

- Open a note and press the **paperclip** at the top right (next to the pin). Pick one or more files.
- The files show as cards under the note's text. **Click a card** to open the file in its usual app
  (PowerPoint, a PDF reader, Explorer for a zip). The arrow **saves a copy** where you choose; the ✕
  takes it off the note (Undo is offered for a few seconds).
- Focus keeps its own copy of each file (in its data folder), so moving or deleting the original
  doesn't affect the note.

## On the phone

- Same paperclip in an open note. Android's file picker opens (Downloads, Drive, Photos …); you can
  pick several files.
- Tap a card to open the file in an app on the phone (Android asks which app if there are several).
  The arrow opens Android's save screen to keep a copy anywhere (for example Downloads).

## How files travel

- A note's file list arrives straight away with the sync. The file itself follows right after the
  note's text, in the same sync. While it's on its way the card is dashed and says
  **"arriving 45%"**; before the next sync it says **"on your other device"**.
- Link to PC / Sync page shows the transfer: *Receiving files 1 of 2 (Week 3.pptx) · 4.1 MB of 9.8 MB*.
  After the sync it says how many files moved.
- The phone's background sync (every ~15 min on Wi-Fi) brings files too. Big files are quickest with
  both apps open.
- A transfer cut off half-way (Wi-Fi drops, app closed) just starts that file again next sync.
- Files are encrypted on the way, like everything else Focus syncs, and go only between your paired
  devices.
