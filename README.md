# Kairos

## About
Kairos is a focus app for Windows. It has a focus timer, stopwatch and countdown, and blocks distracting apps and websites during focus or on a schedule. It also has to-dos, deadlines, notes and a calendar.

Kairos is still being worked on, so new features and fixes come often.

## Installing
The installer isn't code-signed yet, so Windows Defender SmartScreen may show "Windows protected your PC". Click **More info**, then **Run anyway**. The app updates itself after that.
